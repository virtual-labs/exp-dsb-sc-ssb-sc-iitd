Instructions for DSB-SC / SSB-SC Side-by-Side Comparison

  • Note: This page generates one message signal and modulates it with both DSB-SC and SSB-SC (upper sideband), so you can directly compare the two.
  • Step 1: Use the sliders to set message frequency, carrier frequency, and message gain.
  • Step 2: Click "Generate Comparison" to plot the DSB-SC and SSB-SC signals side by side, both from the same message and carrier.
  • Tip: DSB-SC keeps both sidebands (twice the bandwidth of the message); SSB-SC keeps only one, so its spectrum occupies half the bandwidth.
